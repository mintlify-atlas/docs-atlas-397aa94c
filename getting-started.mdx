Follow the steps below to have a fully functioning local instance of Flatiron Support Troop running in under five minutes.

## Prerequisites

Before you begin, make sure you have the following:

- **Node.js 18 or higher** — [nodejs.org](https://nodejs.org). Run `node -v` to check your current version.
- **A Spotify Developer account** — create a free app at [developer.spotify.com](https://developer.spotify.com/dashboard) to obtain a Client ID and Client Secret.
- **An OpenWeatherMap account** — sign up at [openweathermap.org](https://openweathermap.org/api) and generate a free API key (the _Current Weather Data_ plan is sufficient).

---

<Steps>

  <Step title="Clone the repository">
    Run the following command to clone the project and move into its directory:

    ```bash
    git clone https://github.com/amsahwney/flatiron-support-troop.git && cd flatiron-support-troop
    ```
  </Step>

  <Step title="Install dependencies">
    Install all Node dependencies using your preferred package manager:

    <CodeGroup>

    ```bash npm
    npm install
    ```

    ```bash yarn
    yarn install
    ```

    ```bash pnpm
    pnpm install
    ```

    </CodeGroup>
  </Step>

  <Step title="Create your .env file">
    Create a `.env` file at the project root and populate it with your API credentials:

    ```env
    VITE_SPOTIFY_CLIENT_ID=your_spotify_client_id_here
    VITE_SPOTIFY_CLIENT_SECRET=your_spotify_client_secret_here
    VITE_WEATHER_KEY=your_openweathermap_api_key_here
    ```

    | Variable | Where to find it |
    |----------|--------------------|
    | `VITE_SPOTIFY_CLIENT_ID` | Spotify Developer Dashboard → your app → **Client ID** |
    | `VITE_SPOTIFY_CLIENT_SECRET` | Spotify Developer Dashboard → your app → **Client Secret** (click "View") |
    | `VITE_WEATHER_KEY` | OpenWeatherMap → Account → [API keys](https://home.openweathermap.org/api_keys) |

    <Warning>
      Variables prefixed with `VITE_` are **inlined into the browser bundle at build time**, which means anyone who inspects your compiled JavaScript can read them. Never commit your `.env` file to version control. The project's `.gitignore` already excludes `.env`, but double-check before pushing to a public repository.
    </Warning>
  </Step>

  <Step title="Start the development server">
    Launch Vite's development server:

    ```bash
    npm run dev
    ```

    Vite will print a local URL — by default **http://localhost:5173** — which you can open in any modern browser. Hot module replacement is enabled, so changes to source files reflect immediately without a full page reload.
  </Step>

  <Step title="(Optional) Run a local JSON server for feedback">
    The app's feedback form submits responses to the hosted endpoint at `https://fist-json-server.onrender.com/responses`. **No local server is required** for this feature — the hosted instance is always available.

    If you prefer to run your own local JSON server (for example, to develop offline or to inspect submitted data directly), you can install `json-server` globally and start it on port 3000:

    ```bash
    # Install json-server globally
    npm install -g json-server

    # Create a db.json seed file
    echo '{ "responses": [] }' > db.json

    # Start the server on port 3000
    json-server --watch db.json --port 3000
    ```

    You would then need to update the hardcoded fetch URL in `src/Components/Feedback.jsx` to point at `http://localhost:3000/responses` instead of the Render endpoint.
  </Step>

</Steps>

## Verify Everything Works

Once the dev server is running, open **http://localhost:5173** in your browser. You should see the home screen with the five emotion buttons. Click any emotion — if your Spotify credentials are valid, the playlist tracks will load within a second or two. If the browser prompts you for location permission, accept it to enable the weather widget.

If tracks don't appear, open the browser console. Common issues include:

- `Missing Spotify Client ID or Secret` — your `.env` variables are not being read. Ensure the file is named exactly `.env` and that you restarted the dev server after creating it.
- `401 Unauthorized` from Spotify — your Client ID or Secret is incorrect. Double-check the values copied from the Spotify Developer Dashboard.
- Weather data not loading — the browser may have blocked geolocation, or your `VITE_WEATHER_KEY` is invalid or not yet activated (new OpenWeatherMap keys can take up to two hours to activate).
